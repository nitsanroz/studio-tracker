# Gmail connection — one-time Google Cloud setup

Leads Phase 2 reads lead conversations from Gmail, **read-only**. This is the
one-time setup in Google Cloud, done by a Workspace admin (Nitsan). About 15
minutes. Nothing here costs money at the studio's volume.

Sign in to <https://console.cloud.google.com> with your **@studionmore.com**
account.

## 1. Create the project

1. Top bar → project picker → **New project**.
2. Name: `studio-tracker`. Organization: `studionmore.com`. **Create**, then make
   sure it is selected in the top bar.

## 2. Turn on the two APIs

**APIs & Services → Library**, search and **Enable** each:

- **Gmail API**
- **Cloud Pub/Sub API**

## 3. Consent screen — Internal

**APIs & Services → OAuth consent screen** (may be called **Google Auth
Platform → Branding / Audience**):

1. User type / Audience: **Internal**. This is what makes it work for
   @studionmore.com accounts only, with no Google review.
2. App name: `Studio&more Tracker`. Support email: yours. Developer contact:
   yours. Save.
3. **Data access / Scopes** → Add scope → paste
   `https://www.googleapis.com/auth/gmail.readonly` → Update → Save.

## 4. OAuth client

**APIs & Services → Credentials → Create credentials → OAuth client ID**:

- Application type: **Web application**. Name: `tracker`.
- **Authorized redirect URIs** — add both:
  - `https://tracker.studionmore.com/api/gmail/callback`
  - `http://localhost:3000/api/gmail/callback`
- **Create**. Copy the **Client ID** and **Client secret** — you need them in
  step 7.

## 5. Pub/Sub topic (how Gmail tells the tracker a mail arrived)

**Pub/Sub → Topics → Create topic**:

1. Topic ID: `gmail-leads`. Leave "Add a default subscription" **unticked**.
   Create.
2. On the topic page → **Permissions** (right panel, "Show info panel") →
   **Add principal**:
   - Principal: `gmail-api-push@system.gserviceaccount.com`
   - Role: **Pub/Sub Publisher**
   - Save. (If an org policy refuses this "domain restricted sharing", tell
     Claude — there is a workaround.)
3. Copy the topic's full name, e.g. `projects/studio-tracker-123456/topics/gmail-leads`.

## 6. Push subscription

**Pub/Sub → Subscriptions → Create subscription**:

- ID: `gmail-leads-push`. Topic: `gmail-leads`.
- Delivery type: **Push**.
- Endpoint URL:
  `https://tracker.studionmore.com/api/gmail/push?token=<GMAIL_PUSH_SECRET>`
  — Claude gives you the secret value (step 7).
- Acknowledgement deadline: **60** seconds. Leave the rest. Create.

## 7. Hand the values over

Give Claude (or add to Vercel → Project → Settings → Environment Variables,
Production, and to `.env.local`):

| Variable | Value |
| --- | --- |
| `GOOGLE_CLIENT_ID` | from step 4 |
| `GOOGLE_CLIENT_SECRET` | from step 4 — **add this one yourself**, don't paste it in chat |
| `GMAIL_PUBSUB_TOPIC` | the full topic name from step 5 |
| `GMAIL_PUSH_SECRET` | generated by Claude, also in the step 6 URL |
| `GMAIL_TOKEN_KEY` | generated by Claude — encrypts the stored Gmail tokens |
| `CRON_SECRET` | generated by Claude — protects the daily renewal job |

Then each of you opens **Settings → Leads → Connect Gmail** in the tracker and
approves read-only access once.
